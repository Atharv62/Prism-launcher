# Contributing

Thanks for taking a look. Prism is a small project, so keep changes small and focused.

- Run it with `npm install` then `npm run dev`.
- Open an issue first for anything bigger than a bug fix, so we can agree on the approach.
- Match the surrounding code: TypeScript, React, Tailwind, no new dependency for a few lines.
- Say what you tested in the pull request. There is no test suite yet.
- Prism is a launcher: it does not host content, download media or bypass DRM or paywalls, and changes that do will not be merged.
